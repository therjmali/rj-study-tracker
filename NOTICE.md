# Notices

## Vyxel Apps (design)
The **Vyxel** theme (colour tonal palette, corner radii and motion curves) is ported from
[Vyxel Apps](https://github.com/NikhilKain/vyxel-apps) by Nikhil — © 2026, licensed AGPL-3.0.
Only design values (colours, radii, easing/spring parameters) were reused as CSS variables; no Vyxel source code was copied.
The in-app updater was written from scratch against public Android and GitHub APIs.

## AI providers
Google Gemini, Groq, OpenAI, Anthropic and Cohere are third-party services. You use them with your own API key and under their own terms; this app only sends your requests to the provider you choose.
