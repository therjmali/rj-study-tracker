**Forgot password?**
- The sign-in screen's *Forgot password?* now opens a real recovery flow: enter your e-mail → receive a 6-digit code and a reset link → choose a new password → you are signed in. Works in the browser/PWA and in this Android app (the typed code is the in-app path).
- Reset links are removed from the address bar immediately and only verified when you submit the new password, so e-mail scanners cannot use them up. Dead or reused links explain themselves and offer a fresh e-mail.
- After a reset every other device is signed out. Same password rules as sign-up (8+ characters, a letter and a number). Wrong codes, rate limits and reused passwords show clear messages, and nothing reveals whether an address has an account.
- One-time Supabase setup (Site URL, redirect URL, e-mail template, SMTP): see SUPABASE_SETUP.md → "Password reset".
